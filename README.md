# usefulscripts
Some useful scripts with description

## Scripts

- [`studio3t-license-tool/`](studio3t-license-tool/) - finds and cleans up
  stale Studio 3T license state on Windows so a newly-imported license
  isn't shadowed by leftover data.
- [`teamsharing-restore/`](teamsharing-restore/) - restores a Team Sharing
  Atlas backup into a local MongoDB Docker container for Studio 3T, and
  cleans it all up again afterwards.
